# Planos

Um diretório por spec de `vagou-specs`, com o mesmo número:

```
plans/001-onboarding-acesso/
├── plan.md    ← como (decisões citando os requisitos da spec + Conferência da constituição)
└── tasks.md   ← passos pequenos, cada um com forma de verificação
```

A spec correspondente fica em `../vagou-specs/specs/<nnn>-<feature>/spec.md`.
